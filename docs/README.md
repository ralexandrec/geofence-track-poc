# Project Documentation

This documentation set captures the current design, architecture decisions, API contract, and developer setup for the `tracking-app` NestJS service.

## Structure

- `architecture/` — Architectural Decision Records (ADRs), design rationale, and architecture diagram placeholder.
- `specs/` — Core Software Design Document content.
  - `features/` — Functional specifications by capability.
  - `api/` — API contract definitions and request/response models.
- `guides/` — Practical usage and setup guidance.
